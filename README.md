# 🌌 David Leonardo Portfolio

Welcome to my very first portfolio — a playful little portal that blends engineering, creativity, and curiosity into one landing page. This project is the digital front door to my story: robotics, AI, full-stack development, and the ideas I’m building around them.

> If you’re curious, this is the place where the journey starts. 🚀

## ✨ What this app does

This is a single-page portfolio website designed to:

- Introduce who I am through a bold hero section and personal message
- Showcase my expertise in robotics, AI, and full-stack development
- Highlight standout projects with a Bootstrap carousel
- Offer contact options through LinkedIn, email, and a quick message form
- Display my location on an interactive world map

## 🧠 How it works

- The app is built with plain HTML, CSS, and JavaScript
- Bootstrap powers the layout, navigation, buttons, carousel, and responsive styling
- Leaflet.js renders the interactive map and location marker
- JavaScript adds a few polished touches:
  - a sticky navbar that hides after inactivity
  - a copy-to-clipboard email action
  - form validation with a success toast message
  - responsive behavior across screen sizes

## 📁 Main files

- `index.html` — page structure, sections, content, and the app logic/scripts
- `style.css` — custom styling, layout adjustments, and responsive rules
- `CNAME` — custom domain configuration for `david-leo.club`
- `photo.png`, `page-logo.png`, `robotics-logo.svg`, `ai-logo.svg`, `dev-logo.svg` — visual assets used throughout the portfolio

## 🚀 How to use it

- Open `index.html` directly in a browser, or
- Serve the folder with any static server if you want a local preview

## 🎯 Why this project matters

This portfolio is more than a website — it’s a first chapter. A place where ideas, skills, and ambition meet the world. If you want to see the story behind the work, this is the point of launch. 🌍
